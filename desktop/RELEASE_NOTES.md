## 0.1.8 更新

以下功能都需要在设置 → 高级设置 → 生成式判定里选 "Anthropic API" 并填好密钥；没选时界面上不出现。

- **请 Claude 整理（主题页）**：Claude 查看这个主题在你库里的论文和资产，建议定义（仅限还没有定义的主题）、别名、上下位主题、应合并的主题和挂错的条目，每条带把握度和理由。建议先对照资料库检查，再进审核队列的"整理建议"；采纳一条就是一个可撤销的决策，跳过的不会再出现。命令行：`rhz organise <主题>`。
- **请 Claude 判断（审核队列）**：主题之间的关系（是否同一主题、谁属于谁）改由一个先查看资料库再判断的 Claude agent 给出建议和理由，建议的按钮会被高亮。"采纳有把握的建议"可以一次采纳把握度 ≥ 80% 的建议。新摄入产生主题问题后和每晚会自动跑一次；命令行：`rhz agent-review`。
- **修复（重要）**：0.1.7 里开着 API 后端时，每次重算都会重新请求复习题和上下位判断，重复计费。现在这些判断记在资料库里，重算直接取用，不再重复请求。

## 0.1.7 更新

- **Anthropic API 后端（可选，默认关闭）**：设置 → 高级设置 → 生成式判定里选 "Anthropic API"，三类窄判定（主题关系、上下位、复习题文字）改由 API 回答，每次一条短请求，论文文本不会为别的用途发出。默认模型 claude-opus-5-5，可改。密钥存在系统凭据管理器（Windows Credential Manager），不进 settings.json；也可用环境变量 ANTHROPIC_API_KEY，或 `rhz settings secret anthropic_api_key`。密钥缺失、认证失败、限流、断网时都退回审核队列，不影响摄入。
- **每月主题摘要**：MCP 新工具 `rhz_topic_changes(topic, days)`，给 Claude 这段时间内主题子树新增的论文（带 tldr）、资产（带边类型）和矛盾数，由它写"本月新增 / 改变了什么 / 未决矛盾"。
- **导出语言落到别名**：RXF 的 `language` 字段决定非汉字别名的语言（汉字一律 zh，中文导出里的英文名仍记为 en），论文节点也记下语言。

## 0.1.6 更新

## 0.1.5 更新

- **集群 / 远程机器**：快照可放在只读目录或网络盘上直接用；`rhz sync` 只连一次 SSH（一次密码 / 二次验证）；忘记指定快照时会提示，不再悄悄新建空库；支持 Python 3.10。
- **图谱更可信**：你的想法不会被自动并进模型的想法；论文"反对"某论断时不再误记为支持；多篇论文对同一数据集的描述不再互相覆盖；边的证据按导出分别保存。
- **不丢数据**：原始文件写入时落盘同步；数据库提交更保险；`rhz recover --from-raw` 可以只凭 raw 文件夹重建资料库；`rhz export` 导出开放格式；外置备份目录会同步镜像 raw/。
- **大库更快**：向量索引不再反复复制；快照瘦身；周合成按批计算；局部图在数据库里分页。
- **复习与审阅**：可以暂停某张卡或某个资产的全部卡片；"重来"的卡会在本次复习里回来；无本地模型时主题回溯只排前 30 条并可一键全部跳过；论文卡里可以直接改写自己的想法。
- **导出更宽容**：聊天里带说明文字或 ``` 围栏的导出也能识别；报错提示改为"移到 assets 下 / 改名为 text"而不是"删掉"；主题可带别名，缩写与全称会被识别为同一主题候选；非 UTF-8 文件给出明确提示。
- **界面**：搜索分页与真实计数；启动时沿用后端语言设置；后退不再回到加载页；论文卡显示摘要、作者、链接；有新版本时首页提示；对比度和键盘可达性修正。
- **安全与运维**：`/health` 对未认证请求只报活；非回环 Host 被拒；设置和诊断包里不再出现数据库密码；安装器升级前先询问；日志按角色分文件并轮转；模型固定到具体版本；发布包附校验和与第三方声明。

## 0.1.4 更新

- **升级更安全**：数据库升级前自动备份，失败会回滚并保留原库；新版本创建的资料库被旧版本打开时会明确提示，而不是损坏数据。可以从备份一键恢复。
- **长任务不再卡住其他操作**：重算、夜间整理分段进行；重复提交的任务自动合并；任务列表可看到进度和失败原因。
- **模型属于资料库**：换嵌入模型后索引会标为过期并提示重算，不会把不同模型的结果混在一起。
- **纠错渠道**：可以撤回或替换某次导出、否决某个实体，所有决策可在历史里撤销。
- **导入更宽容**：中文代码仓库、各种 DOI 写法、物种名自动识别；OpenAlex 暂时连不上时稍后自动补全，而不是当成“没有元数据”。
- **大库更快**：高连接实体和宽主题分页显示；中文关键词按词匹配，中文别名参与排序。
- **出了问题看得见**：日志按 应用/Claude/命令行 分文件；页面出错显示错误编号并可复制详情；后端停止时窗口给出原因和日志末尾，可一键重试；收件箱页面显示等待中和无法识别的文件。
- **资料库位置更稳**：迁移先复制到临时文件夹再切换，中断不会留下半份数据；找不到资料库时提示并可重置位置，而不是悄悄新建一个空库。
- 快照同步到远程时文件仅自己可读。

## 0.1.3 更新

- **自动备份**：每天自动备份一次资料库，旧备份自动清理；备份文件夹可以设到另一块硬盘或网盘（设置 → 备份）。
- **重算不再卡死**：某条人工决策过期时（例如换模型后实体消失），重算会跳过它并列出编号，而不是整体失败；重算前只做一次备份。
- **实体编号稳定**：重算后每个实体保持原来的编号，网址和 Claude 里引用的编号不再错位。
- **Claude 连接更稳**：应用重启后，Claude Desktop 里的 Rhizome 工具自动重连；迁移资料库后 Claude 不会再写进旧位置。
- **设置只保存你改过的项**：以后版本改进的默认值能生效；设置文件损坏时自动用备份恢复，而不是无法启动。
- **找回导出指令**：设置 → 聊天 Project 设置，可一键复制 RXF 导出指令、下载主题词表；Claude 也能通过 `rhz_rxf_guide` 自己获取。
- **召回修复**：空内容、没有 import 的脚本、Jupyter notebook 都能正常召回；长文本召回不再变慢。
- 选了安装版无法加载的模型时，每页顶部会提示并可一键改回内置模型。
- 自动化测试现在每次提交都运行，发布前必须全部通过。

## 安装 / Install

1. 双击安装包。安装包**尚未代码签名**，Windows 可能提示"Windows 已保护你的电脑"：点 **更多信息 → 仍要运行**。
2. 安装位置可以任选（支持中文和空格路径），默认 `%LOCALAPPDATA%\Rhizome`，不需要管理员权限。
3. 从开始菜单打开 Rhizome。资料库默认在 `%APPDATA%\Rhizome`，可在"设置 → 存储"里迁移；卸载和升级都不会删除资料库。
4. 在"设置"里点 **接入 Claude Desktop**，重启 Claude Desktop 后即可使用 `rhz_*` 工具。

The installer is not code-signed yet: on the SmartScreen prompt choose *More info → Run anyway*.
Per-user install (no admin rights), any folder incl. non-ASCII paths. Your library stays in
`%APPDATA%\Rhizome` (movable in Settings) and survives upgrades and uninstalls.
